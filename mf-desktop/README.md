# mf-desktop — Project Tracker (Electron)

Cross-platform desktop client for MasterFabric Project Tracker. Same backend as **mf-web** / **mf-expo** / **mf-macos**:

| Surface | Path |
|---------|------|
| Auth, orgs, personal todos, org chat | mf-go GraphQL |
| Org projects / issues / purchases | `particularGraphqlEnvelope` → Particular `project_tracker` |

## Stack

- Electron + electron-vite + React 19 + Tailwind 4
- Shared API: [`packages/mf-tracker-client`](../packages/mf-tracker-client)
- Session tokens via Electron `safeStorage` (IPC)
- System tray, hide-to-tray, floating dashboard, local focus timer
- Issues / Board / Timeline with filters
- Per-task **GitHub** links in the issue drawer (PR / issue URL or `#n`); default `owner/repo` (+ optional PAT) in **Settings → GitHub**
- Packaging: electron-builder (`dmg` / `nsis` / `AppImage`); updates via `electron-updater` (GitHub Releases)

## Prerequisites

1. **mf-go** running (default `http://127.0.0.1:8080/graphql`)
2. **particular-project-tracker** registered and reachable through mf-go
3. Client app `com.masterfabric.monoExpo` linked to your org in MasterFabric Core → Apps

### Local stack (typical)

```bash
# Infra (Postgres :5433). Host Redis on :6380 is fine — set REDIS_PASSWORD= empty in mf-go/.env if host Redis has no auth.
cd ../masterfabric-core-base/mf-go && make docker-infra   # if Redis port 6380 conflicts, start only postgres/rabbit/mailpit

# API
cd ../masterfabric-core-base/mf-go
set -a && source .env && set +a
export REDIS_PASSWORD=    # when using passwordless host Redis on 6380
make build && ./bin/server

# Particular (Agile todos / sprints)
cd ../masterfabric-particulars/particular-project-tracker
PARTICULAR_JWT_SECRET='local-dev-secret-not-for-production-use!!' PORT=39205 go run .

# Register + refresh client env
cd ../masterfabric-particulars
./scripts/register-project-tracker-local.sh
./scripts/print-mf-project-tracker-env.sh > ../masterfabric-project-tracker/local.env
cd ../masterfabric-project-tracker && npm run mf-desktop:env
```

If the desktop shows **API unreachable**, mf-go is down. If orgs still fail after Retry with a signed-in user, **sign out and sign in again** (stale refresh tokens after a DB reset).

## Environment

Same contract as **mf-web** / **mf-expo**, mapped from repo-root `local.env`
(generated by `masterfabric-particulars/scripts/print-mf-project-tracker-env.sh`):

| Desktop (`VITE_*`) | Source (`local.env` / Expo) |
|--------------------|-----------------------------|
| `VITE_GRAPHQL_URL` | `EXPO_PUBLIC_DEV_GRAPHQL_URL` or `EXPO_PUBLIC_GRAPHQL_URL` |
| `VITE_MF_BUNDLE_ID` | `EXPO_PUBLIC_MF_BUNDLE_ID` |
| `VITE_MF_API_KEY` | `EXPO_PUBLIC_MF_APP_API_KEY` |
| `VITE_MF_PROJECT_TRACKER_PARTICULAR` | `EXPO_PUBLIC_MF_PROJECT_TRACKER_PARTICULAR` |
| `VITE_GITHUB_REPO` | Optional default `owner/repo` for task `#n` links (Settings) |
| `VITE_GITHUB_TOKEN` | Optional PAT (prefer linking in Settings — stored in userData) |
| `VITE_MF_CORE_URL` | Core admin base URL (Apps integrations deep-link) |

```bash
# From repo root (preferred)
npm run mf-desktop:env
# or: ./scripts/sync-desktop-env.sh
# optional: ./scripts/sync-desktop-env.sh --web   # also refresh mf-web/.env.local
```

Do **not** commit `mf-desktop/.env` (gitignored). Template: [`.env.example`](.env.example).

## Develop

```bash
# Repo root — sync env from local.env, then run
npm run mf-desktop:env
cd mf-desktop && npm install && npm run dev
```

### Scripts

| Script | Purpose |
|--------|---------|
| `npm run env:sync` | Write `.env` from repo-root `local.env` |
| `npm run dev` | Electron + Vite HMR |
| `npm run build` | Compile main / preload / renderer → `out/` |
| `npm run pack` | Unsigned dir build via electron-builder |
| `npm run dist` | Platform installers under `release/` |

## Desktop features

- **Main window** — full AppShell (dashboard, projects, issues, purchases, my work, team, chat, settings)
- **Tray** — Show Window, Pin Desktop Dashboard, Quit
- **Close** — hides to tray by default (Settings → Desktop)
- **Dashboard widget** — floating glance window (tasks / focus / chat)
- **Focus timer** — 25 / 15 / 5 minute local timer (Settings)
- **Settings** — GraphQL URL override, open mobile (`masterfabricexpo://`), check updates

## Notes

- Does **not** replace **mf-macos** WidgetKit on Mac; Electron is the Win/Linux (+ optional Mac) companion.
- Refresh tokens use `platform: "desktop"` / `deviceName: "mf-desktop"`.
- Code signing is not required for local `pack`; production `dist` needs Apple/Windows signing for store-quality installs.
